## 安装方法

安装包是**未签名**的 IPA（文件名带 `ios-unsigned`），需要用签名工具装到手机上，常见的有：

- 电脑：爱思助手、Sideloadly、AltStore
- 手机：全能签、轻松签、Feather、TrollStore（巨魔，支持的系统版本可直接装）

用自己的 Apple ID 签名的话，**7 天后需要重新签一次**（免费账号的限制），收藏和观看进度不会丢。

## 常见问题

**会覆盖原来装的吗？**
用同一个签名工具、同一个证书重新签同一个包名，会直接覆盖升级，数据保留。

**手机和电脑之间怎么同步？**
在「设置」里配置「设备互联」或 WebDAV（坚果云、群晖、OpenList 都行），各设备填**同一套**配置即可。电脑版可以在设置页生成二维码，手机扫一下就能自动填好。

**以前在安卓下载页下载 iOS 包？**
iOS 包从这一版起单独放在这里，安卓下载页不再放 IPA。
